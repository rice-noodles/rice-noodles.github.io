三、put 流程

1. 入口方法

2. 核心逻辑（putVal）

核心步骤：

  1. 哈希计算：hash = (key == null) ? 0 : (h = key.hashCode()) ^ (h >>> 16)（扰动函数减少碰撞）。
  2. 定位桶索引：(n - 1) & hash。
  3. 处理哈希冲突：
    • 链表插入：遍历链表直到找到空节点或相同 key。
    • 树化：链表长度 ≥8 时转红黑树（需数组长度 ≥64，否则优先扩容）。
  4. 扩容检查：元素总数超过 threshold（容量 × 负载因子）时触发 resize()。

3. 扩容（resize）

扩容逻辑：

  1. 容量翻倍：新容量 = 旧容量 × 2。
  2. 数据迁移优化：
    • 单节点直接定位到新桶。
    • 链表拆分为高位链和低位链（利用 (e.hash & oldCap) == 0 判断）。
    • 红黑树拆分时可能退化为链表（节点数 ≤6）。

1. 入口方法

2. 核心逻辑（getNode）

关键点：

  • 哈希定位：(n - 1) & hash 快速找到桶。
  • 节点查找：
    • 链表遍历时间复杂度 O(n)。
    • 红黑树查找时间复杂度 O(log n)。

五、总结

操作 时间复杂度 核心逻辑
初始化 O(1) 延迟初始化，容量为 2 的幂次方
put O(1)~O(log n) 哈希定位 → 链表/树插入 → 扩容检查
get O(1)~O(log n) 哈希定位 → 链表/树遍历
resize O(n) 容量翻倍 → 数据迁移优化
